# Changelog

## 0.2.0

- Execute registered HTTP agents with real connection checks and bounded responses.
- Persist queued runs, immutable version manifests, per-episode progress and failure state.
- Enforce cancellation, worker leases, action idempotency and terminal episode boundaries.
- Seal complete snapshots and traces and grade them in a separate interpreter.
- Check sustained recovery from causal state, structured root cause and diagnostic evidence.
- Add two-fault hard scenarios, seeded variations and adversarial log instructions.
- Add release QA, complete package inclusion and self-hosted deployment definitions.
- Connect all dashboard views to real records; export reports and paired comparisons.

This release is a typed simulation, with an explicit reference oracle. Independent model
calibration, a live containerized microservices world, and additional domains remain future work.
